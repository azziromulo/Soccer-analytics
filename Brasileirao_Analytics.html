          Dados

          As cinco tabelas do modelo. O botão de cópia gera TSV: cole no Excel ou em “Inserir dados” no Power BI. A coluna Escudo de dTime traz a imagem como data URI (categoria de dados: URL da imagem).

          Escudos dos clubes

          dTime[Escudo]

          Os 44 clubes usam os escudos do arquivo escudos-clubes-brasileiros.zip, convertidos para PNG. Para trocar algum, carregue a nova imagem aqui ou arraste para este quadro. Dá para enviar vários de uma vez: o nome do arquivo identifica o clube, por exemplo Flamengo.png, sao-paulo.svg ou FLA.png. As imagens ficam salvas só neste navegador e passam a valer em todas as páginas, inclusive no simulador.

          Qualidade dos dados

          Modelo semântico

          Esquema estrela: uma tabela fato por clube-temporada, três dimensões ligadas a ela e dEstado em floco a partir de dTime. As tabelas tracejadas são desconectadas e só alimentam o simulador. Passe o mouse numa tabela para destacar os relacionamentos.
